# Dashboard Kit Reference Intake

Status: active

Purpose: reference intake for the Nous Hermes dashboard kit gallery and standards control-plane surface.

Mobbin/reference basis:
- mobbin.com/screens/analytics-dashboard-reference
- mobbin.com/screens/design-system-gallery-reference
- mobbin.com/screens/component-library-reference
- mobbin.com/screens/data-visualization-review-reference

Patterns extracted:
- Component galleries must show live rendered examples, not only inventory text.
- Review states must be visible as approved, reviewing, draft, deprecated, and needs-redesign.
- Chart examples must include axes, legends, comparison controls, time windows, and empty/error/proof states.
- Project adoption evidence must be tied to route, component, screenshot, and proof status.

Acceptance notes:
- This intake covers the standards gallery/control-plane route only.
- Downstream project dashboards must maintain their own project-specific reference intake before Tier 3 promotion.
