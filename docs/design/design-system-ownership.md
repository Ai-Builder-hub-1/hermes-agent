# Design System Ownership

Hermes OS is the governance and enforcement layer for dashboard standards.

`@hermes/dashboard-kit` owns shared dashboard primitives, tokens, recipes,
validation contracts, and package-native starter rules. Downstream projects own
their domain data, route composition, production deployment, and project-specific
copy.

Mobbin provides reference evidence only. It does not own Kaoshi/Hermes visual
identity, tokens, accessibility decisions, or component APIs.

Tier 3 promotion requires evidence from both sides:

- Hermes/NouS Hermes Agent: standards, validators, registry, proof expectations,
  and shared component contracts.
- Project repository: package-native implementation, live telemetry contracts,
  production proof endpoint, screenshots, and clean adoption status.
